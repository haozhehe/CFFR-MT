# CFFR-MT
A web-based Campus Facility Fault Report and Maintenance Tracking System. 

Problem – university relies on email, calls, and verbal communication to report problems such as broken computers, damaged furniture, light issues, classroom equipment. Reports can be sent to the wrong department or forgotten.  

Solution – We will develop a web-based Campus Facility Fault Report and Maintenance Tracking System. Students and staff will be able to submit maintenance requests by selecting the building, room number, issue category, priority level, and providing a description with optional photo uploads. Maintenance staff will be able to review reports, update repair status, assign technicians, and record repair notes. Administrators will have access to a dashboard to monitor open and resolved issues, overdue requests, and maintenance statistics. The system will also include search, filtering, notifications, and user role management. 


Language: TypeScript
Framework: Next.js
Frontend: React
Styling: CSS
Version control: GitHub
AI-assisted coding: GitHub Copilot
Testing: Playwright
